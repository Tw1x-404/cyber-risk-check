# cyber-risk-check

A small Python tool for a basic cyber risk assessment. It connects what I
know from insurance (how risks are assessed) with what I'm learning in
cybersecurity.

## Status

Planned. I'm working on the basics in Python first.

## Idea

- Answer a short questionnaire (e.g. backups, MFA, updates, employee training)
- Calculate a simple risk score from the answers
- Show the biggest weak spots and basic recommendations

## What I want to learn

- Structuring data and calculating scores in Python
- Common security measures and why they matter
- Turning a risk assessment into a working tool
